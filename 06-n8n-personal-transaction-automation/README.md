# n8n Personal Transaction Automation

**n8n | Gmail | Google Sheets | Workflow Automation**

**A self-initiated personal automation project** that processes transaction notification emails and automatically organizes transaction data in Google Sheets for **monthly expense and budget tracking**.

---

## Why I Built This

Building Excel VBA automations for my work sparked my interest in broader process automation.

After completing a two-day hands-on n8n course, I applied what I learned by building this workflow for personal use — turning repetitive transaction tracking into an automated monthly expense tracking process.

---

## Solution

The workflow automatically:

1. Retrieves transaction notification emails from Gmail.
2. Extracts and formats transaction details.
3. Filters invalid transactions.
4. Categorizes transactions using predefined rules.
5. Checks existing and previously deleted records to prevent duplicates.
6. Updates new transactions in Google Sheets.
7. Sorts transaction records by date and time.
8. Runs automatically on a scheduled basis.
